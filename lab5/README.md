## Запуск

```bash
cd lab5
docker compose build
docker compose up -d
```

Проверка API:

```bash
chmod +x tests/smoke.sh
./tests/smoke.sh
```

Проверка rate limiting (ожидается 429 после 100 запросов в том же минутном окне):

```bash
chmod +x tests/rate_limit.sh
./tests/rate_limit.sh
```
