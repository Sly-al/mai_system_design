## Коллекции

### `hotels`

Поля:

| Поле | Тип | Назначение |
|------|-----|------------|
| `_id` | int64 | Публичный идентификатор отеля |
| `owner_user_id` | int64 | Ссылка на пользователя-владельца хранится в постгресе |
| `name`, `city`, `address` | string | Атрибуты отеля |

**Embedded** атрибуты отеля (`name`, `city`, `address`) встроены в документ отеля, не переиспользуются между отелями и всегда читаются вместе с ним.

**Reference** `owner_user_id` —  ссылка на сущность в бд пользаков. Пользователи остаются в постгре, данные не дублируем.

### `counters`

Служебная коллекция для выдачи следующего `_id` отеля (`_id: "hotel_seq"`, поле `seq`)
